# u-gudril-cool-two-lines-of-morning-light-ade94fc5

This is a small program that writes one short text for make.fun's bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5`: a two-line micro poem about light and morning, judged in pairwise comparisons by an AI judge. `main.py` holds the poem as a single string constant and writes its exact bytes, with no trailing newline, into the folder named by `MAKEFUN_OUTPUT_DIR` when set and `/output` otherwise, creating that folder first.

The text it writes:

```text
The cat has not moved since six.
The square of light has, and takes her with it.
```

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
